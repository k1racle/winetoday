## 1. Общие принципы

| Параметр                                                         | Значение                                                                                                                                               |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Макс. ширина контента                                  | `max-w-7xl` (1280px), боковые отступы `px-4`                                                                                                 |
| Текстовая колонка (биографии, описания) | `max-w-3xl` (768px) по центру левой зоны                                                                                                    |
| Тема                                                                 | светлая/тёмная — как у сайта (`bg-background`, `text-foreground`); акцент — тот же `accent` (лайм)                |
| Заголовки страниц                                        | `font-heading`, 36px, акцентное подчёркивание (как заголовки архивов)                                               |
| Карточки персон/вин                                     | как`ArticleCard`: обложка сверху, подпись снизу, скругление 0 (квадратные углы — стиль сайта) |
| Сетка карточек                                              | 3 колонки десктоп (`lg`), 2 планшет (`sm`), 1 мобайл                                                                            |
| Хлебные крошки                                              | `Главная / Виноделы России / …` — uppercase 11–12px, `text-foreground/50`                                                          |

## 2. Кнопка входа в шапке

Кнопка «Виноделы России» — в ряду иконок справа, **слева от поиска**. Не в полосе рубрик.

```
Десктоп-шапка (основной сайт):
┌──────────────────────────────────────────────────────────────────────────┐
│  ЛОГОТИП                       [Виноделы России] [🔍] [☰] [☀] [A]        │
│                               ^ текстовая кнопка   поиск  соц  тема аккаунт│
├──────────────────────────────────────────────────────────────────────────┤
│  НОВОСТИ | РОССИЙСКОЕ ВИНОДЕЛИЕ | …рубрики без изменений…                │
└──────────────────────────────────────────────────────────────────────────┘

Кнопка: text-xs font-bold uppercase tracking-wider, как пункты меню,
hover → text-accent. Не иконка — текстовая ссылка (важный вход в проект).
```

Мобильное меню: пункт «Виноделы России» первым, над «Новости» и рубриками, выделен `text-accent`.

`Избранные виноделы` — только по флагу `featured`; если отмеченных персон мало, блок допускает 2–4 карточки, а при полном отсутствии флага скрывается целиком.

## 8. Терруар и хозяйство

**Терруар `/terroirs/[slug]`:** крошки → заголовок → карта с одним маркером (250px) → факты (экспозиция, высота, почвы) → описание → вина терруара → «Материалы о терруаре».

**Хозяйство `/wineries/[slug]`:** крошки → заголовок + логотип справа (если есть) → факты (основано, регион → ссылка) → описание → виноделы хозяйства → вина хозяйства → связанные материалы.

Оба — одноколоночные, структура повторяет страницу региона.

Если у хозяйства нет логотипа, шапка не резервирует пустой слот справа. Если у терруара не заполнены отдельные факты, выводим только непустые строки.

## 10. Интерактивная карта

```
┌──────────────────────────────────────────────────────────────────────────┐
│  Leaflet + OSM. Высота: 420px лендинг / 380px регион / 250px терруар.    │
│                                                                          │
│   ● — регион (крупный маркер, accent)                                    │
│   • — терруар (мелкий маркер); кластеризация при плотности               │
│                                                                          │
│  HOVER на маркере → всплывающая карточка (поверх карты, ~240px):         │
│  ┌────────────────────────────┐                                          │
│  │ Терруар «Скалистый»        │  ← заголовок-ссылка                      │
│  │ Тамань, Краснодарский край │  ← регион, text-foreground/50            │
│  │ Виноделы:                  │                                          │
│  │  · Илья Волошин →          │  ← до 3 ссылок на персон                 │
│  │  · …                       │                                          │
│  │ 12 вин · подробнее →       │  ← ссылка на страницу терруара           │
│  └────────────────────────────┘                                          │
│  Клик по маркеру → переход на страницу региона/терруара.                 │
└──────────────────────────────────────────────────────────────────────────┘
```

Карта — client-only (`<ClientOnly>`), стили Leaflet в отдельном чанке. В карточке на карте список персон ограничиваем 3 ссылками; остальные сворачиваем в `+N`.

## 11. Генеалогическое древо

```
SVG-граф, слои по поколениям (поколение = горизонтальный ряд, ритм 120px):

  ┌─────────────────────────────────────────────────────────┐
  │   (○дед)──(○бабка)        (○отец)══(○мать)              │  ← брак: ══
  │        │                      │                         │  ← parent: ──
  │        └──────────┬───────────┘                         │
  │                [ ◉ ИЛЬЯ ]═══(○супруга)                  │  ← текущая:   │
  │                     │               рамка accent + фото │     крупнее   │
  │            ┌────────┴────────┐                          │
  │         (○сын)            (○дочь)                       │
  └─────────────────────────────────────────────────────────┘

Узел: круглое фото 56px + имя (12px) + годы (10px, /50).
Текущая персона: ◉ 72px, рамка border-2 border-accent.
Hover на узле → тултип: имя, годы, хозяйство. Клик → страница персоны.
Горизонтальный скролл на мобильном; высота по числу поколений.
Нет связей → блок не рендерим.
```

## 13. Мобильная адаптация

| Блок                          | Правило                                                                                                                                                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Шапка раздела         | поиск — иконкой, раскрывается по тапу (как в основной шапке)                                                                                |
| Лендинг                    | карта 300px высотой; избранные — 2 колонки; архив табами горизонтальным скроллом                                              |
| Персона                    | фото 160×200 по центру, факты под ним; таймлайн и древо — со скроллом; карточки вин/материалов — 1–2 колонки |
| Вино                          | таблица фактов над описанием, одной колонкой                                                                                                          |
| Карта                        | попап — bottom-sheet на весь низ экрана вместо hover (тап по маркеру)                                                                                |
| Пагинация/фильтры | как в архивах: фильтры переносятся в 2 строки                                                                                                           |
